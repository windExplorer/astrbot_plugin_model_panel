# 模型控制台（astrbot_plugin_model_panel）

> 本文档是项目的核心上下文，任何 AI / 开发者打开本仓库都应先读此文档，避免重复调研。
> 记录：本插件的需求、技术结论、依赖的 AstrBot 核心 API、以及已确认的实现方案。

## 一、定位

一个独立的 **AstrBot 模型管理与检测插件**，通过自带 WebUI（模型控制台）统一完成：模型延迟/存活检测、排序、默认模型查看、以及伴侣插件精准模型的一键批量替换。

- 插件目录 / 包名：`astrbot_plugin_model_panel`
- 展示名：**模型控制台**
- WebUI：Vue3 + Vite + hash 路由，作为 AstrBot 面板页面展示（非弹窗）

## 二、功能需求

1. **控制台**：全局总览。
2. **模型检测排序**：
   - 读取全局 LLM（chat）模型，展示
   - 延迟检测 + 存活检测
   - 排序功能
   - 单独检测 / 一键检测
   - 检测开关：关闭后"一键检测"跳过该模型
3. **默认模型切换**：只读展示 AstrBot 当前默认模型（写入能力后续再做）。
4. **伴侣插件模型替换**（最核心）：
   - 读取伴侣插件（astrbot_plugin_private_companion）的精准模型配置
   - 一键批量替换模型（把精准配置里已使用的模型批量换成新模型）
   - 未选择替换的保持原样

## 三、技术方案（基于 AstrBot 4.27.4 源码确认）

AstrBot 核心源码位置（调研时）：`_References\AstrBot`（版本 4.27.4）。
注意：`_References\AstrBot-master` 是旧版 4.26.6，勿混淆。

### 后端（Python, AstrBot Star 插件）
- 继承 `Star`，`context.register_web_api(...)` 注册 Web API
- **获取 chat 模型**：`context.get_all_providers()` → `list[Provider]`（含 `provider.config`、`provider.meta()`）
  - embedding：`context.get_all_embedding_providers()`（本项目只做 chat）
- **延迟/存活检测**：`await provider.test(timeout=45)`（发 "REPLY PONG" 测延迟，异常即不存活）
- **AstrBot 默认模型（只读）**：`context.provider_manager.provider_settings["default_provider_id"]`
  - 注意 `provider_settings` 来自 `acm.get_conf(umo)["provider_settings"]`
- **读伴侣插件 providers**：`context.get_registered_star("astrbot_plugin_private_companion").config`
  - `StarMetadata.config` 是 `AstrBotConfig`（dict 子类，有 `save_config()`）
  - 伴侣插件 providers 直接存在插件配置里（key 如 `FAST_RESPONSE_PROVIDER_ID` 等，见伴侣插件 `_allowed_provider_keys()`）
  - 写：改 `config[key]` 后 `config.save_config()`（零侵入，不改伴侣插件代码）
- **保存插件自身配置**：`AstrBotConfig` 支持 `config[key]=...` + `save_config()`

### WebUI（Vue3 + Vite + hash 路由）
- 构建参考：comfyui-anima 的 `webui-src/vite.config.ts`
- **必须**：`base: "./"`、`inlineDynamicImports: true`、`cssCodeSplit: false`（单文件产物）
  - 原因：AstrBot 插件页面只对入口 index.html 直接引用的资源重写 asset_token；跨 chunk import 在旧版会 401 白屏。单文件产物最稳。
- 路由用 `createWebHashHistory`（hash 路由，无需 SPA fallback）
- 产物输出到 `pages/model-panel/`（metadata.yaml 的 pages 注册）

### 插件配置文件
- `metadata.yaml`：name、display_name、version、author、pages（注册模型控制台页面）
- 用 `@register` 装饰器或 metadata 注册

## 四、页面结构（Vue3 hash 路由）

路由设计：
- `/` → 控制台（总览）
- `/detect` → 模型检测排序
- `/default` → 默认模型（只读展示）
- `/companion` → 伴侣插件模型替换

## 五、部署要点

- 依赖 AstrBot `>=4.22.0`（本插件的 `astrbot_version`）
- 安装：把插件目录放入 AstrBot `data/plugins/`
- WebUI 在 AstrBot 面板中展示
